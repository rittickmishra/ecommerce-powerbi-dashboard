# E-commerce Sales Dashboard (Power BI)

## Overview
This project analyzes e-commerce sales data to track performance, profit, and trends across different regions and categories.

## Key Features
- Total Sales, Profit, and Order KPIs
- Monthly and yearly sales trends
- Top-performing products and categories
- Region-wise performance analysis
- Interactive filters (category, region, date)

## Tools Used
- Power BI
- DAX
- Data Modeling

## Insights
- Identified top revenue-generating categories
- Observed seasonal spikes in sales
- Found regions with lower profitability
